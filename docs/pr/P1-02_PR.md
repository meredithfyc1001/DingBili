# PR: feat(p1-02): 路由、生命周期协调、资源所有权与原版无残余恢复

- 分支：`feat/p1-02-routing-lifecycle` → `feat/p1-01-baseline-build`（基于 PR [#1](https://github.com/meredithfyc1001/DingBili/pull/1) 的叠栈 PR）
- 候选版本：`0.1.0-p1.2`

## 变更摘要

1. **文档级与页面级生命周期彻底解耦（`src/core/history.js`、`src/core/lifecycle.js`）**
   - 实现协作式 `installHistoryBridge`，保留既有与后装第三方 History 包装器并对同 tick 同 URL 事件去重，卸载时不覆盖他方包装。
   - 实现单例 `createLifecycleCoordinator`，在未支持路径冷启动时保持轻量文档路由监听；从未支持路径通过 SPA 进入支持页时可正确挂载外壳（修复 `KF-02`）；支持 `pagehide`/`pageshow` BFCache 挂起与重建，以及单调 `generation` 失效保护以丢弃过时异步回调。
2. **严格资源所有权与原版无残余恢复（`src/core/ownership.js`）**
   - 新增 `createDocumentOwnership`，追踪并仅在脚本仍持有所有权时还原 `document.title`、favicon（不再误删原 `#orig` ID）、根元素类/属性/CSS 变量、`inert` 与挂载前焦点，自动保留挂载期间宿主网站新写入的元信息（修复 `KF-01`）。
   - 新增 `createSessionScope`，统一托管并幂等清理会话级监听器、`MutationObserver`、定时器、`rAF`、`AbortSignal` 与脚本注入样式节点。
3. **运行时无重载切换与防死父节点保护（`src/baseline/legacy-runtime.js`、`baseline/BASELINE_BEHAVIOR.md`）**
   - 将菜单“原版 B 站”、悬浮按钮 `.xim-fab` 与评论区“原版评论”切换由整页 `location.reload()` 改为同文档无重载会话卸载/挂载，并在 `.xim-fab` 上阻止 `mousedown` 抢焦以保证原版焦点无损还原。
   - 修复 `restoreParkedVideo()` 在原宿主父节点已脱离 DOM 时将其强行放回已断开父节点的问题；关闭并记录 `KF-01` 与 `KF-02` 基线缺陷。
4. **单元测试与全量 E2E 验证（`tests/unit/p1-02-lifecycle-ownership.test.mjs`、`tests/e2e/p1-02-routing-lifecycle.spec.mjs`、`tests/e2e/p1-01-baseline.spec.mjs`）**
   - 新增 History 共存、资源所有权、SessionScope 幂等清理与 LifecycleCoordinator 单元测试。
   - 新增 A02.1、A02.2 × F1–F4（含亮/暗色恢复、宿主新写入保护、焦点还原、脱离父节点保护、`pagehide`/`pageshow` 合成 BFCache 校验、冷启动与 20 次往返压测）Chrome + Edge 自动化用例。
