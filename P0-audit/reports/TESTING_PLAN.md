## 如何复现隔离样本

1. 用空临时 `--user-data-dir` 启动 Chrome，开启 `--headless=new --remote-debugging-port=0 --disable-extensions --disable-sync --disable-background-networking`。仅连接本次进程在临时目录发布的 DevTools 端口。设置 `--proxy-server=http://127.0.0.1:9` 与 `--host-resolver-rules=MAP * ~NOTFOUND`，再从该标签页启用通配的 CDP `Fetch.enable`。对两个预期 origin 的 Document 执行 `Fetch.fulfillRequest` 返回下述 UTF-8 HTML 样本，其余请求 `Fetch.failRequest`。这样脚本看到真实的 URL 和 origin 语义，整个测试标签页的数据由本地生成。
2. 启用 `Page`、`Runtime`，记录 `Runtime.exceptionThrown`，以 `Page.addScriptToEvaluateOnNewDocument` 的 source 提供上列哈希的完整文件文本。只在注入及拦截都启用后导航到模拟首页。以下 DOM 先于 `DOMContentLoaded` 构造。每次整页刷新重新构造；同文档 history 操作保留原 DOM，便于区分脚本清理与整页重载。
3. 首页使用 `<title>Fixture Native</title>`、`<link rel="icon" id="orig" href="data:,native">` 和 `main#app > article.bili-video-card`。为卡片放入 `h3 > a[href="https://www.bilibili.com/video/BV1ab1234567/"]`、“样本作者 · 昨天”的 `.bili-video-card__author` 以及文本 123 的 `.bili-video-card__stats--text`。按 T02 插入同 ID、不同 ID（BV2cd2345678）的卡片并编辑原节点。按 T03 的路由顺序检查。不要在赋予真实页面活动的标签页中模拟。
4. 同一测试上下文访问搜索 URL，使用同样卡片结构，加上 `.vui_pagenation [aria-current=page]` 与 `button[aria-label=下一页]`。按钮仅记录回调，更新原锚点 ID、标题及页码。使用 `音乐` 关键词让本地分区和视频同时命中，检查两个结果链接的解析后 `hostname`。模拟服务器不为错误域名应答。
5. 视频样本采用 `#viewbox_report h1.video-title`、带真实样式结构的 `a.up-name`，以及 `#player-origin > #bilibili-player > video`。给播放器设置 `style="height:188px"`，并在其后放置有独立 ID 的兄弟元素。在搬运前保存对象引用。为 video 提供本地生成的 WebM Blob 地址，可用 `canvas.captureStream(20)` 与 VP8 `MediaRecorder` 录制约 0.6 秒交替色帧，设置静音循环。观察真实 play 事件及 `currentTime` 推进，再检查恢复顺序。
6. 在已知父节点及相邻节点间放入 `bili-comments`。它的开放影子根内放 `bili-comment-box` 和 `bili-comment-thread-renderer`，前者影子根含 `#footer > #pub > button`。后者影子根放 `bili-comment-renderer[rpid="1"]`、`bili-comment-reply-renderer[rpid="2"]` 和显示“共2条回复”的 `#view-more button`。两条评论自己的开放影子根内均放 `#user-name`、`#contents` 和文字为“回复”的 button。展开按钮仅插入 rpid=3 并删除自身，回复按钮仅记录自身 rpid。三项文本依次为“一级样本”“回复 @样本甲：二级样本”“回复 @样本乙：后续样本”。按 T06 操作。每个异步动作须等待数据或 DOM 断言成立，截图不足以验证原生按钮是否被触发。

7. 性能探针只统计精确选择器。分别构造 30 与 300 张具有唯一 av ID 的卡，等消息全部出现并再等 1.2 秒。临时包装该合成页面的 `document.querySelectorAll`，仅统计与 JS L1021 的 CARD 字符串完全相同的调用；包装 `Element.prototype.querySelector`，仅统计宿主 `article.bili-video-card` 上按 JS L1082 的首个复合标题选择器查找的次数，包装均原样代理到浏览器方法。观察 650ms，清零，往 `#app` 追加一个空 `span`，再观察 650ms。每组结束恢复原方法。
