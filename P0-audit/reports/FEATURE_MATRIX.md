# DingBili P0 功能矩阵

审计对象为 BiliShu 0.6.1，Git 提交 `da8b9722a778c94440e826a02559c8da3692b546`。下文所有 `L` 行号均指本次快照的 [bilishu.user.js](../upstream/bilishu.user.js)。验证环境及动作见 [TESTING_PLAN.md](TESTING_PLAN.md)。T 系列使用隔离合成页面，H02 使用钉钉皮肤在匿名 B 站实站只读采样，H03 在一个真实 BV 视频上检验普通播放。表中「静态」代表逐段核对源码、没有专门执行该项；M1、M2 是本文末尾的离线函数探针。未做与官方钉钉、飞书、企业微信客户端逐像素对比，也未登录真实用户账户。

## 三套主题的交付边界
