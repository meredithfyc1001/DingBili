## 三、P0 未验证能力与覆盖边界（Unverified — 不可标为通过）

以下能力在 P0 及 P1-01 均未获得等价实测证据，在相应验收阶段提供实际证据前一律记为 `NOT TESTED` 或 `BLOCKED`：

1. **真实登录态与公开写入**：登录态头像/个人空间跳转、真实公开评论发送、子回复发送、取消后发顶层评论的服务端回执（P1-05 / P1-06 需获授权人工测试）。
2. **完整原生播放器能力**：真实站点多 P 切换、起播定位、倍速、全屏进出、弹幕开关、清晰度切换、有声播放及原父节点被站点替换后的恢复（P1-05）。
3. **真实用户脚本管理器扩展装载与 Firefox 覆盖**：本机 P1-01 自动化使用 Playwright `addInitScript` 在 Windows Chrome 158 与 Edge 158 中复核构建产物注入与 `@noframes` 语义；未在本机自动化安装 Tampermonkey/Violentmonkey 扩展，本机亦未安装 Firefox（待 P1-08 实际管理器组合覆盖，A01.2 实扩展安装项如实记为 `NOT TESTED` / `BLOCKED`）。
4. **钉钉桌面视觉参考图逐屏签收**：尚未指定官方参考版本与截图（P1-07）。
5. **长时压力与内存/资源基线**：同一轮 ≥30 分钟、≥100 次有效会话切换、≥50 轮视频详情完整开关周期与 F1–F4 退壳（P1-08）。
